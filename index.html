Project-X Drive Sync

Project-X Drive Sync is a private tool. It keeps one shared Google Drive folder and a folder on its owner's own computer in step, using the open-source program rclone.

It is used by its owner and a few invited collaborators. It is not a public service and has no sign-up.

When you sign in, the tool asks Google for access to your Google Drive files so that it can read and update the shared project folder. Files are copied only between Google Drive and the computer running the tool.
